# hunt-8bit

8-bit 自動狩獵伴侶：右側 pane 常駐，獵人（大劍）跟著 Claude 的主回合出營、狩獵魔物（冰呪龍與八隻新增魔物）、撤退。美術方向來自 `hunt_8bit_reference`（v1.2）參考包，以像素改編為準，不是原作素材。

## 第一版範圍

- 動作 15 組（交接文件第一里程碑）：C01／C03／C08／C15／C17、G03／G05／G06、V01／V02／V14／V17／V23／V25／V26；太刀與弓在武器列停用並標 v2。
- 場景：S03 營地；狩獵場 S02 與 S04 每場輪替，一場中途不換景；S01 已擷取備用。
- 連動：主回合開始時出營或續打；回合完成時鏡像跑離並回營（HP 補滿、進度保存）；中斷時畫面凍結並顯示「暫停」；子代理的回合忽略。`working_elapsed` 只計主回合，含工具時間。
- 結束規則：冰呪龍有隱藏血量，跨回合、跨 session 累積（`$.store`，全域只有一位獵人），歸零時播 V25 倒地完成討伐，下一個回合再開新一場。獵人力竭時播 C17 回營，冰呪龍的血量保留。
- 戰鬥：本機規則加權重的隨機狀態機（`hooks/engine.ts`），數值在 `hooks/data.ts`。冰呪龍血量由固定種子的模擬自動校正到 `targetMinutes`（目前 5 分鐘）。40 場模擬平均 5.1 分鐘、約 38% 的場次會力竭。
- 營地（v0.3）：回合之間獵人會走到營火旁烤肉、吃肉；回合開始立刻出營。
- 魔物註冊（v0.4）：魔物是 `hooks/monsters/` 下的資料定義（招式、數值、專屬機制），引擎不再寫死冰呪龍。新狩獵依種子從已啟用的魔物抽一隻，一場中途不換種。已啟用：冰呪龍（S02／S04，5 分鐘）、大凶豺龍（S01 森林，2 分鐘）、飛雷龍（S01 森林，3 分鐘）、蠻顎龍（S01 森林，4 分鐘）、冰牙龍（S02 雪原，5 分鐘）、迅龍（S01，5 分鐘）、轟龍（S02，5 分鐘）、雷狼龍（S01，6 分鐘）、殲世滅盡龍（S05 結晶廢墟，7 分鐘）。
- 大凶豺龍（v0.4，依 `hunt-8bit-monster-expansion-spec-v1.0` 4.1）：前咬、腹部重壓、側身翻壓、吐出胃液團；戰鬥 20 秒後膨腹 20 秒（較慢、只用重壓與翻壓），腹部打破即消腹並倒地 24 tick。胃液團是獨立特效，飛行中才有攻擊框。
- 飛雷龍（v0.5，規格 4.2）：前咬、躍身撲擊（跳起 28px、前撲 80px，框跟著根部高度）、迴身尾掃（前後兩側）、帶電尾砸；戰鬥 12 秒後蓄電 12 tick，蓄電中受傷達最大 HP 5% 即中斷；完成後帶電 16 秒才會出帶電尾砸，時間到或受傷達 15% 放電收招。只有直接傷害，沒有麻痺。
- 蠻顎龍（v0.6，規格 4.3）：俯身咬擊、低頭衝撞（前移 120px，停在獵人身前）、回身尾掃、火焰吐息；戰鬥 20 秒後抬鼻冠、展背帆 12 tick，期間受傷達最大 HP 5% 即中斷；完成後火焰準備 18 秒才會吐火（近／中距，準備期間不主動走近），每次吐息後冷卻 12 tick。火焰只向前、畫在攻擊框上，只有直接傷害、沒有灼燒。
- P2／P3（v0.7，規格 4.4–4.9）：冰牙龍（翼部破壞、落地失衡、固定冰旋風）、迅龍（怒後二連尾砸、尾卡地空檔、三連尾棘）、轟龍（折返衝刺、怒時三段、三次後疲勞）、雷狼龍（蓄電量、超帶電與雷電爆發、三連拍）、殲世滅盡龍（白／黑棘、破棘倒地或硬直、鎖定落點的俯衝）。迅龍與轟龍共用怒氣規則。S05 結晶廢墟由 `tools/make_s05.py` 畫出（參考包沒有這張圖）。
- 碰撞（v0.2）：只有攻擊框在有效姿勢碰到受擊框才扣血，同招對同目標只算一次；獵人會跑近、往後翻滾，冰呪龍只用碰得到的招。框在 `hooks/collision-data.ts`，pane 的「除錯 ▾ → 碰撞框」可疊在畫面上看。

## 指令

- `/hunt`：開啟 pane。
- `/hunt-demo`：不經 Claude 回合，手動切換狩獵或撤退（除錯用）。
- `/hunt-demo <魔物 id>`（例 `/hunt-demo great_jagras`）：丟棄進行中的狩獵，立刻出營打一場指定魔物（除錯用；討伐與力竭次數保留）。
- pane 下方的「除錯 ▸／▾」：顯示狀態機、事件與 SVG 字元數（上限 131,072）。

## 素材管線

`tools/extract_sprites.py` 依 `tools/extract_spec.json` 從參考包擷取：

- 動作板以原圖 1:1 擷取。處理只有：從裁切邊緣灌填去背、去除封閉的底色區塊、切除地面線、把各格平移對齊 F1（不改像素）、同群組共用調色盤量化。大劍板放大 1.25 倍，對齊 01／02 板的身高。
- 場景縮成 128×72、16 色，顯示時放大 3 倍。
- 輸出到 `hooks/gen/*.ts`，每列以 RLE 儲存（引擎讀取單檔的上限是 1 MB）。

```bash
PYTHONUTF8=1 python -I tools/extract_sprites.py <hunt_8bit_reference 資料夾>
```

新增魔物來自另一個參考包，用 `--only <group>` 只重擷取該群組（不動其他群組與場景）：

```bash
PYTHONUTF8=1 python -I tools/extract_sprites.py <hunt-8bit-all-monsters-reference-v1.1 資料夾> --only jagras
```

`--sheet <png>` 輸出擷取總覽圖，`--measure` 只量測尺寸。

## 已知限制與 v2 項目

- 特效沒有分層：吐息、刀光、冰屑保留在角色影格裡。命中只依資料裡的 `active` 姿勢判定，不從發光像素推定。分層列為 v2。
- 每組動作只有 F1–F4 四個關鍵姿勢，沒有補中間影格，也沒有逐幀校正持武器的手。
- 參考板之間的比例不一致：獵人和冰呪龍的相對大小沿用各板原樣，冰呪龍維持 1:1。
- 未實作：太刀、弓、武器切換點擊、V29 死亡動作、S05 的正式美術（目前是程序產生的佔位圖）。
