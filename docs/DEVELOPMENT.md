# hunt-8bit 開發說明

給要改這個 mod 的人：設計範圍、素材管線與已知限制。使用者介紹在 [README.md](../README.md)（中文版 [README.zh-TW.md](../README.zh-TW.md)），接手時的決策與檔案地圖在 [HANDOFF.md](../HANDOFF.md)。

獵人（大劍、太刀或弓）跟著 Claude 的主回合出營、狩獵冰呪龍、撤退。美術方向來自 `hunt_8bit_reference`（v1.2）參考包，以像素改編為準，不是原作素材。

## 目前範圍

- 動作 25 組：C01／C03／C08／C15／C17、G03／G05／G06、L01／L02／L03／L05／L06、B01／B04／B05／B06／B07、V01／V02／V14／V17／V23／V25／V26（營地另有 C02／C21）。
- 場景：S03 營地；狩獵場 S02 與 S04 每場輪替，一場中途不換景；S01 已擷取備用。
- 連動：主回合開始時出營或續打；回合完成或被中斷時，一律鏡像跑離並回營（HP 補滿、進度保存），沒有暫停；子代理的回合忽略。`working_elapsed` 只計主回合，含工具時間。
- 結束規則：冰呪龍有隱藏血量，跨回合、跨 session 累積（`$.store`，全域只有一位獵人），歸零時播 V25 倒地完成討伐，下一個回合再開新一場。獵人力竭時播 C17 回營，冰呪龍的血量保留。
- 戰鬥：本機規則加權重的隨機狀態機（`hooks/engine.ts`），數值在 `hooks/data.ts`。冰呪龍血量由固定種子的模擬，依大劍自動校正到 `targetMinutes`（目前 5 分鐘）；太刀與弓的傷害再各乘一個由模擬校正的倍率，三把武器的狩獵時間相近。各 40 場模擬：大劍平均 5.4 分鐘、23% 力竭；太刀 5.1 分鐘、25%；弓 5.9 分鐘、58%（v0.5 修正出招判定後重調閃避率；這個統計雜訊約 ±15%）。
- 武器（v0.4）：回合一結束，pane 下方就有「大劍／太刀／弓／隨機」按鈕，獵人還在跑回營地時也能按。選定的武器立刻換上；回合進行中按鈕換成文字、不能換。畫面左下角的「武器 ○○」只是顯示，點了沒有作用。「隨機」在每開一場新狩獵時抽一把，續打同一場時不換。太刀：縱斬連段、袈裟斬，硬直或倒地時用氣刃大迴旋斬。弓：通常射擊、快速射擊，硬直或倒地時用剛射，能從遠處出手。
- 營地（v0.3）：回合之間獵人會走到營火旁烤肉、吃肉；回合開始立刻出營。
- 碰撞（v0.2）：只有攻擊框在有效姿勢碰到受擊框才扣血，同招對同目標只算一次；獵人會跑近、往後翻滾，冰呪龍只用碰得到的招。框在 `hooks/collision-data.ts`，pane 的「除錯 ▾ → 碰撞框」可疊在畫面上看。

## 指令

- `/hunt`：開啟 pane。
- `/hunt-demo`：不經 Claude 回合，手動切換狩獵或撤退（除錯用）。
- pane 下方的「除錯 ▸／▾」：展開後只有「碰撞框」開關（狀態機、事件等除錯文字已移除）。

## 素材管線

`tools/extract_sprites.py` 依 `tools/extract_spec.json` 從參考包擷取：

- 動作板以原圖 1:1 擷取。處理只有：從裁切邊緣灌填去背、去除封閉的底色區塊、切除地面線、把各格平移對齊 F1（不改像素）、同群組共用調色盤量化。大劍板與太刀板放大 1.25 倍，對齊 01／02 板的身高；弓板 1:1。太刀板每格都畫了冰呪龍，靠每格的右邊界與 `blank` 區塊排除，被切到的刀光就停在冰呪龍的輪廓前。
- 場景縮成 128×72、16 色，顯示時放大 3 倍。
- 輸出到 `hooks/gen/*.ts`，每列以 RLE 儲存（引擎讀取單檔的上限是 1 MB）。

```bash
PYTHONUTF8=1 python -I tools/extract_sprites.py <hunt_8bit_reference 資料夾>
```

`--sheet <png>` 輸出擷取總覽圖，`--measure` 只量測尺寸。

## 已知限制與 v2 項目

- 特效沒有分層：吐息、刀光、冰屑保留在角色影格裡。命中只依資料裡的 `active` 姿勢判定，不從發光像素推定。分層列為 v2。
- 每組動作只有 F1–F4 四個關鍵姿勢，沒有補中間影格，也沒有逐幀校正持武器的手。
- 拿太刀或弓時，待機、營地走路、出營與撤退的跑步都換成持武器步移（L01／B01），閃避換成面向冰呪龍往後滑（太刀 L06 看破斬的後撤段、弓 B07 蓄力步伐），所以跑起來像快步走。受擊、倒地（C15／C17）仍是共通動作，畫面上看不到武器。
- 參考板之間的比例不一致：獵人和冰呪龍的相對大小沿用各板原樣，冰呪龍維持 1:1。
- 未實作：其他太刀與弓的招式、V29 死亡動作、其他魔物、S01 的使用。

## 示範動圖

README 的 `docs/media/demo.gif` 由遊戲自己的 SVG 產生，不是另外畫的：

```bash
npx -y tsx tools/demo_frames.mts demo-frames en
```

```bash
PYTHONUTF8=1 python -I tools/svg_to_gif.py demo-frames docs/media/demo.gif --scale 2
```

繁中版：`demo_frames.mts` 的語言參數改成 `zh-TW`，輸出 `docs/media/demo.zh-TW.gif`。

`svg_to_gif.py` 只畫遊戲用到的 SVG 子集（一像素高的橫線、矩形、文字、平移與鏡像），需要 Pillow 與 Windows 的微軟正黑體、Consolas。
